# Python Data Structure Operations

This repository contains Python programs demonstrating basic operations on different data structures.

## Programs Included

### 1. String Operations

* Creating a string
* Accessing characters
* Slicing
* Indexing
* Finding length
* Updating strings
* Concatenating strings

### 2. List Operations

* Creating a list
* Accessing elements
* Indexing
* Slicing
* Adding elements
* Removing elements
* Modifying elements
* Searching elements
* Sorting elements
* Reversing elements

### 3. Tuple Operations

* Creating a tuple
* Accessing elements
* Indexing
* Slicing
* Concatenation
* Deleting tuples
* Nested tuples

### 4. Set Operations

* Creating a set
* Accessing elements
* Adding elements
* Removing elements
* Handling duplicate elements
* Understanding unordered collections
* Demonstrating mutable (changeable) nature of sets

### 5. Dictionary Operations

* Creating a dictionary
* Accessing dictionary elements
* Adding elements
* Removing elements
* Accessing keys
* Accessing values
* Understanding ordered dictionaries
* Handling duplicate keys
